# Starbyte and Cheatarium

Starbyte can read Cheatarium's **versioned SNES index** using an explicit local file. No automatic internet access or ROM scan is introduced by this command.

```sh
cargo run -p starbyte-cli -- cheatarium --index /path/to/snes.json.gz --title 'Donkey Kong Country'
cargo run -p starbyte-cli -- cheatarium --index /path/to/snes.json.gz --title 'Donkey Kong Country' --json
```

The `snes.json.gz` bundle is generated by [Cheatarium](https://github.com/sguzman/cheatarium) and lives at `generated/v1/snes.json.gz` in that project. Select a pinned revision of Cheatarium, then supply the file locally. You do not need the raw archive to run this lookup.

**Important:** the results are suggestions based on indexed filenames, *not* verified matches to the currently loaded ROM. They include original source, revision, code strings, and related metadata. The command **does not enable any cheats**, change emulator memory, download files, or claim that encoded Game Genie and Action Replay strings are directly writable SNES addresses.

This is a narrow first consumer integration. Future work: checksum/build-aware identification, convenient game UI, per-device decoding and tests against known SNES versions. Do not automatically pass the returned source codes into `FrontendSession::set_active_cheats`, whose existing parser only supports a subset of raw memory-write formats.
